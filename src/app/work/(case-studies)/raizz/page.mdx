## Context

**AxiLab** is an AI sleep-technology startup building personalized, real-time
sleep optimization for wearable devices. I joined as the sole product designer
for the summer and owned design across the whole product.

Over the internship I:

- Redesigned the **Raizz** mobile app end to end and designed new features for
  both the existing and redesigned apps: **160+ screens and states across 7
  feature areas and 25+ flows**.
- Built a **scalable design system** so a small team could keep shipping
  consistently after I left.
- Authored a **PRD for an AI-driven daily sleep-planning feature**, translating
  user feedback, behavioral data, sleep research, and business strategy into
  personalization logic, recommendation prioritization, user flows, and success
  criteria.
- Rebuilt the marketing site's front end for a major redesign and supported beta
  operations for 50+ users through feedback analysis, log reviews, and
  engineering collaboration.

## The problem

The existing app had grown feature by feature. Sleep data, coaching, device
management, and settings each followed their own patterns, so the product felt
larger and more complicated than the value it delivered. New features had
nowhere consistent to live.

## Approach

I worked in three overlapping tracks:

1. **Audit and restructure.** Map every existing screen, group flows by user
   intent, and define a navigation model that had room for the roadmap.
2. **Design system first.** Establish tokens, typography, and core components so
   redesigned screens and brand-new features shared one language.
3. **Design the AI planning feature.** Partner with the founders on the PRD, then
   design how a personalized daily plan is generated, explained, and adjusted.

## Design system

A token-driven library of color, type, spacing, and elevation, feeding a set of
components documented for the two engineers who would maintain it. The redesign
and the new features were both built entirely from it.

## Outcome

The redesign gave the product a coherent structure and a system the team could
build on without a designer in the room for every decision. The AI
daily-planning feature shipped into beta on top of it.
